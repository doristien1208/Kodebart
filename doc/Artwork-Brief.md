# 開始封面／素材交接

背景資產：`assets/kodebart-cover.png`。原始生成圖保留，封面標題與選單另由HTML呈現；不把文字烘焙進圖。

本輪使用內建圖片生成工具。定位：冷色像素風、夜間柯迪巴特接待大廳。此為開始畫面設計提案，不宣稱已定義機構完整建築。沒有繪製0102或任何未定巴特族外觀。

構圖：左40%留給標題與選單；接待台在中央，右側為雨窗、座椅與走廊。門口的光表面友善，壓迫感來自空間與安靜，不直接放刑具、血跡或敵人。

原始提示詞：

> Use case: stylized-concept. Create ONE background artwork for the start menu of an original Taiwanese Traditional-Chinese psychological narrative game called KodeBart / Error of the world. This is an asset for a real playable UI prototype: landscape 16:9, high-quality deliberate 2D pixel art with crisp pixel clusters, limited 24-color palette, no smooth painting, no vector look. Scene: the clean, quietly welcoming reception lobby of a futuristic social-care institution at night. Huge rain-darkened windows and cold blue city silhouettes on the RIGHT; a reception desk, a small pale cyan terminal, orderly empty waiting chairs and a softly lit doorway receding toward a dark corridor on the CENTER/RIGHT. Ordinary humane corporate architecture, not a prison, not a military base. Oppressive stillness conveyed through emptiness and depth. LEFT 40% is a darker simple navy wall with subtle architecture, intentionally calm negative space for live HTML title and menu to be overlaid. Main focal doorway at x=70%, y=48%. Night navy #0b1424, steel blue #243c56, desaturated cyan #7fcbd1, ice blue #d2e7ed, restrained violet shadows. Detailed pixel dithering, cinematic planar depth and rectangular reflected light across floor; restrained retro adventure-game aesthetic. No characters, no anatomical creatures, no blood, no weapons, no eyes, no glitch or horror slogans, no text, no letters, no logos, no user interface. No imposed story spoilers. Save artwork suitable for integration into the prototype; return local asset path if available.

圖像不強制宣稱只有24色；該數字是生成風格指示，若正式製作需精確色盤，應另行驗證／由美術製作。目前圖片為單張背景，不是p5圖層或可視差素材。後續p5可以疊加雨點等少量效果，但不必為了用工具而重畫整張圖。
