## 0. 每輪協作流程

本檔是唯一的跨工具溝通紀錄，不再另建重複的交接文件。

1. Claude 開始一輪前先讀本文件的「目前階段」「工程任務」「尚待決定」。只處理本輪明列的範圍，不順手展開下一階段。
2. Claude 完成後直接在「Claude 實作回報」新增一筆，列出修改檔案、完成行為、資料／存檔變更、已知限制及需要決定的問題。
3. 使用者通知 Codex 覆核。Codex 每一輪開始時先完整讀本文件的新回報，再讀取對應程式與資料。
4. Codex 只做程式碼、資料、文案與需求符合度覆核，不負責操作測試，也不重複執行 Claude 已做的測試。檢查結果寫入「Codex 檢查結果」，問題改寫成可直接交辦給 Claude 的工程任務。
5. 使用者負責實際操作、節奏、視覺與整體遊戲體驗測試；回饋與「通過／需修改」記錄在「使用者試玩回饋與驗收」。
6. 只有使用者明確驗收後，該小階段才可標為完成並進入下一輪。

若 Codex 在設計十天內容、資料量、敘事揭露或玩法規則時遇到會改變方向的問題，必須先停下來詢問使用者，不自行定案。

### 每輪回報格式

Claude 與 Codex新增紀錄時使用以下欄位，避免只寫「完成」：

- 輪次／日期
- 本輪任務編號
- 修改檔案
- 已完成行為
- 資料、存檔或相容性變更
- 尚未完成／已知限制
- 需要使用者決定
- 下一位負責方

## 3. 使用者已確認的設計與限制

### 遊戲與敘事

- 遊戲名稱為 KodeBart，中文公司名稱為「柯迪巴特」。
- Web 劇情向遊戲，以角色扮演、調查、資料操作、選擇與延後後果為核心；玩法必須與系統架構、程式或資料處理有關。
- 核心命題：每個看似合理的行為都可能影響他人；流程與系統顯示成功，結果仍可能錯誤。不要直接把「語法正確、邏輯錯誤」當成教學答案告訴玩家。
- 主角是普通人類員工，不是英雄，沒有改寫世界因果或任意修改系統的權限。
- 選擇後果不立即公開；透過較晚出現的八卦、報告、新聞等片段讓玩家自行拼出關聯。
- 可保留內部隨機判定；結果可能受到制度或人為干預，但不向玩家直接公開操控機制，也不把所有隨機都寫成陰謀。
- 故事沒有救贖或快樂結局，後果可能不可逆；公司表面仍維持友善、平等與正常上班氛圍。

### 世界觀與 0102

- 柯迪巴特對外宣稱平等友善，實際上控管、抓捕、實驗或奴役巴特族，另有軍用改造計畫。
- 人類有自己的姓名；同事正常用名字稱呼，主角辦公室沒有巴特族員工。
- 0102 是女性巴特人與主要角色之一，目前沒有設定名字，不可擅自命名或解釋她為何沒有名字。
- 童年時 0102 曾在邊界主動幫助迷路的主角並給他食物；事件被監視器拍到，之後她被柯迪巴特以莫須有罪名抓走。
- 上述因果是作者層級設定，不代表玩家一開始知情。不得安排主角立即認出 0102，也不得提前公開完整因果或軍用計畫。

### 技術與視覺

- 規劃方向為 Angular、Tailwind CSS、p5.js 與 Node.js；Cloud Run 是未來選項，不代表目前已完成。
- 不自行加入 SSR 或大幅改造架構。
- 兩天 Demo 的目前試玩方向已獲使用者確認，可以作為階段一基礎；階段一最終目標是完成 **10 天可遊玩內容**。
- 現有資料處理量需要增加，不能讓主要遊玩只剩少量紀錄與短暫點選。
- 工作頁應讓玩家感覺正在操作一台電腦上的公司內部系統平台，而不是一般網站或宣傳頁。
- 頁面與系統模組切換需要加入過渡效果，但不得把每次切換做成恐怖故障或影響工作操作。
- 既有開始頁整體設計已獲使用者肯定；後續要求包含窗外落雨、走廊燈光閃爍，以及本輪主標題 Glitch。
- Glitch 只作用於主標題，保留其字體、位置與大小；每隔隨機 5–10 秒播放約 200–350ms，水平錯位 1–3px 並帶輕微青色色差，關閉動態及 `prefers-reduced-motion` 時停止。
- 第一輪不顯示種族欄位或 string／int 教學；玩家核對「人員編號」，姓名只用一般文字顯示。0102 顯示「姓名：未登記」「人員編號：0102」，前導零須在提交、存檔與重新載入後保留。
- 第一輪指定文字：操作說明「請依來源資料核對人員編號，完成歸檔。」；留空「請填寫人員編號。」；不符「請依來源資料填寫人員編號。」；成功「歸檔完成。」
- 第一輪不新增額外警告、主角疑心旁白或姓名缺漏原因；保留既有提交流程、選項、分支與後續事件紀錄。

### 素材與 UI 實作政策

- UI 能以 HTML、CSS、TypeScript 或 Canvas 完成時，優先用程式碼，不為裝飾性框線、表格、狀態燈、掃描線或轉場另外生成圖片。
- 只有程式碼無法合理完成、且確實能提升場景或敘事辨識度時，Codex 才補生成素材。
- 每一輪最多生成 **2 個素材**；未使用的額度不累積到下一輪。
- 新素材放入 `public/assets/`，檔名需可辨識用途，並在本文件「素材紀錄」記下來源、用途、使用位置與是否已獲使用者接受。
- 不生成 0102 的未定外觀、不替未定角色定型，也不把作者層級秘密做成提前劇透的素材。
