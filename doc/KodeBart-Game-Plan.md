## 1. 遊戲定位

單人 Web 劇情向 RPG，以公司工作介面、調查、角色對話與選擇後果構成遊玩。保留 TRPG 的角色扮演與資訊不完整感；骰子藏在系統內部，不要求玩家手動擲骰。不以移動角色、反覆走路對話為主要體驗。

核心命題：每個人的行為與選擇，都可能影響另一個人的處境。通過規則與程式驗證，不等於在現實中做了正確的事。

玩家是一名活在社會與機構制度中的普通員工。玩家能處理自己權限內的工作，不能任意修改整個世界、控制所有流程或成為拯救體制的英雄。系統架構與程式概念構成玩法，但主角職業不因此改定為全權工程師。

作品整體沒有救贖、沒有快樂結局；表面日常仍可快樂、友善、真誠。造成的傷害具有不可逆性。不可把每個小選擇都寫成必然害人，更不可讓所有選擇毫無差異；局部幫助可以成立，卻不抹除整體悲劇與既成後果。

## 3. 已確認的世界觀

### 社會與柯迪巴特

人類社會普遍將巴特族視為異類。柯迪巴特對外主張平等與友善，實際上捕捉巴特人、進行實驗或奴役。進入者幾乎無法離開；逃脫後被捕者可能遭當場處置。

人類與巴特族的敵意早於公司成立。柯迪巴特利用恐懼、偏見與利益，以維持安全、協助弱勢、提供資源等不同承諾取得支持，並把既有歧視整理為可執行的流程。人類也可能一面排斥巴特族，一面私下利用他們的資源；不追溯至單一仇恨起點，不替巴特族補造特殊能力或獨占物資。

KodeBart 的命名指向 Code Bart：將具有個體意志的巴特族制式化、系統化，變成可控、可運作與可調度的體系。這是機構目的與創作隱喻，不代表每個巴特人真的是電腦程式。

人類員工有姓名，可以正常用名字稱呼同事，擁有日常職場關係。**主角所在辦公室的同事中沒有巴特族**，不擴張成已知全公司任何地方都沒有巴特族員工。不要誤寫成所有員工都只能用編號。

柯迪巴特另有軍用計畫，將巴特人改造成士兵替人類作戰，攻擊對象甚至可能包括巴特族。軍用計畫的階段、規模、技術與具體戰爭尚未定案。

### 主角

主角是人類，童年曾是迷路的小男孩，走到人類與巴特族領域的邊界。成年姓名、具體年齡與外觀尚未定案；Demo 不替玩家定名。

主角曾親眼接觸友善的巴特人，因此無法完全相信社會的污名。當柯迪巴特宣稱要建立平等友善時，他被吸引而加入，並非一開始就以臥底或調查員身分進入。

主角特別之處是這段真實經歷，不是超能力、英雄血統、駭客天賦或特別的系統權限。

男性玩家主角是後來為遊戲加入的入口；原始世界觀核心是 0102，不把她降為主角的救援目標或解謎獎勵。玩家入職時陰謀早已發生，不能趕上某個黃金十日就阻止所有傷害。

### 0102

0102 是主要角色之一，女性巴特人，也是童年幫助主角的人。一般巴特人不會隨意出現在邊界，但她選擇接近迷路男孩，提供幫助與食物。

過程被監視器拍下。不久之後的某日深夜，柯迪巴特以莫須有的罪名將她抓走。這段因果為已確認設定；具體罪名、逮捕日期、主角何時認出她仍未定。

她的名字目前尚未取定。不可把作者尚未命名，擅自解釋成她沒有名字、忘記名字、拒絕透露或名字已遭刪除。這些都需要另行討論。

主角可能因童年事件自責，但迫害責任仍在捏造罪名與執行迫害的人；不要把作品立場寫成「受助的小孩或善意本身有罪」。0102 應具自主性，其願望、判斷與其他關係需後續發展，不只是主角的道德測驗。

### 已確認的作者層因果：兵器化與戰鬥意識

0102 原本溫柔、具有傷害能力卻傾向不用，並非柔弱或潛藏邪惡。被捕後，人類為了使她成為兵器，以反覆刺激、疼痛與命令製造出負責生存與戰鬥的第二人格。它學到疼痛是威脅、暴力使刺激停止、猶豫帶來更強懲罰，以及必須排除威脅、保護 0102；卻沒有被教會信任、憐憫與停止。

失控時攻擊研究員、守衛與設施，是執行人類強加的規則，不是揭露巴特族本性或精神疾病等於暴力。0102 知道它來自實驗、也知道它保護自己，但看過自己的身體殺人後仍害怕，開始懷疑自己是不是怪物。

制度會倒置因果：先施暴與製造戰鬥意識，再以暴走紀錄證明她本來危險；事故的殺傷資料甚至可以繼續服務兵器計畫。玩家最終取得的是理解，不是撤回傷害的勝利。以上是使用者已明示的世界觀，不是前十日可讀文件或本輪新增實驗玩法。

## 4. 舊案保留與未決問題

## 5. 遊玩核心

工作需求 → 閱讀來源與規格 → 操作資料／規則 → 技術驗證通過 → 正常生活與下一項工作 → 較晚取得新資訊 → 重新理解先前行動。

樂趣來自比對、推論、測試與取捨，不是單純閱讀大量文件，也不是為了增加時長重複輸入。每項工作應有明確目標、可觀察的輸入／輸出，以及至少一個值得思考的資料關係。

### 程式與架構如何成為玩法

- 資料核對：所有人員使用同一表單，姓名為文字顯示；玩家手輸人員編號，只驗非空白字串、保留前導零與實際輸入，不要求與來源相等、不一鍵帶入來源。這是使用者後續已確認且目前實作的方向，取代早期照抄才放行的設計。種族與姓名／編號型別差異不作教學，不在第一輪揭露巴特族身分。
- 資料映射：同一份來源可以如何符合目的欄位？資訊在轉換時保留或失去什麼？
- 空值與預設值：沒有紀錄，不代表「否」、更不代表「同意」。錯誤推論可以符合全部技術驗證。
- 權限與資料視野：員工能完成工作，但未必能看到下游處置與全貌。
- 版本與後續程序：玩家提交的資料與隔日收到的報告可能存在差異，差異須有內部因果而不是任意變字。

M1 已實作附件版本、映射、批次輸出與延後退件的骨架；工程存在不等於玩法已驗收。M2 延伸引用與送件包，讓玩家決定下游拿到哪些上下文。前期仍用欄位、文件、預覽與處理動作，不要求玩家寫完整程式或先懂 API、trace ID。

### 延後後果

完成工作只顯示工作層面的結果，例如「驗證通過，已歸檔」。不立刻剪接受害畫面、不標示善惡值、不用音效或紅字提示罪惡選項。

玩家之後透過報告、新聞、同事八卦及人物對話取得片段。來源有各自的資訊範圍、用詞與立場。避免所有人都是陰謀家，也避免每份文件都藏明顯線索。一般生活內容須確實存在。

### 隱藏擲骰與人為介入

保留真正的隨機性：接觸時機、訊息細節、可觀察痕跡可能不同。人為干預是其中一種原因，不是所有隨機結果的統一答案。

以狀態＋玩家選擇＋已定義角色／程序行為＋種子亂數共同判定。已發生的結果存檔，不因刷新、開關報告或UI重繪重新擲骰。關鍵劇情有保底入口，不因運氣差永久卡住。

目前僅確認「背後可能有人搞鬼」的方向；誰、動機、陣營與干預位置未定。不把全部干預預設成敵意，也不把所有異常解釋成非同步競態。

## 6. 敘事與章節方向

全篇尚未有定稿章節。長篇方向採四段：信任與熟悉工作、局部矛盾、認出自己參與的後果、在不可逆處境中繼續選擇；具體揭露與終局仍未定稿。前十日只是一名新人的早期疑問，不足以確認整個制度的傷害；後半部可跳過數週／數月，只詳玩重要工作日，保留既有選擇與未決事項。

0102與童年恩人的關係、拘捕真相、軍用計畫應分層揭露，不能在入職兩天全部揭開。不同結局須在信任、知情範圍、遭遇、證據去向等方面有具體差異，即使都沒有救贖。

## 7. 美術與介面

已確認：冷色調、pixel風格、黑暗題材。開始封面由 Codex 設計。試作方向：深藍夜間接待大廳、窗外冷光、乾淨的座椅與接待台、走廊深處留白。刻意不先展示牢房、血跡或軍用改造。

正式工作介面應比封面更明亮、友善。像素風集中於場景、框線、光點與圖形；繁體中文正文保持可讀，不硬套缺字或過小像素字型。冷色不等於每個工作畫面都陰森，不採黑底綠字駭客終端作為通用風格。

開始頁：錯誤世界／ERROR OF THE WORLD／KodeBart，開始遊戲、繼續、設定。無存檔時繼續停用並有文字說明。設定至少可關閉動態；不放沒有實作的按鈕。

## 8. 技術方向與分工

正式 Demo：Angular CSR＋TypeScript＋Tailwind CSS；p5.js負責需要的畫布特效，不接管表單、文字與可及性。遊戲核心、內容資料、呈現層與存檔介面分離。

先做瀏覽器存檔。Node.js API與Cloud Run為後續選項，不是本輪上線承諾。遊戲本體暫無SSR需求；日後公開介紹頁可以另採SSG。不要為模擬公司架構真的建立微服務群。

- 使用者：世界觀與劇情決策、玩法與美術審閱。
- Codex：遊戲企劃兼 PM、故事與內容資料、UI 目標、源碼／資料與工程證據覆核；不代替 Human 操作試玩，不自行寫遊戲程式。執行與合併邊界沿既有 Agent 流程，不在此重訂。
- Claude：在使用者指定的現有專案整合並實作正式Angular Demo。

早期獨立 HTML 僅是歷史玩法／視覺參考，現有產品是本 repository 的 Angular 專案。不可使用 FlexibleDesignWeb 或其他作品充當本專案。

## 9. 後續驗收問題

玩家能否在沒有教學答案時理解工作？能否區分型別錯誤與邏輯問題？第一次完成工作時是否感到正常？隔日的小差異是否引發自發查閱，而不是只感到遊戲bug？調查是否給新資訊或改變後續回應？介面是否過於像真上班而缺乏推理空間？

以上仍是試玩問題；目前已非只有兩日原型。下一輪以 M2 完整第 7–10 日章節判斷，有可描述的案件決策與人物關係，才算體驗進展；分鐘數只是設計目標，不當作已驗證事實。
